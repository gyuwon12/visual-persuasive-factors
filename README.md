# Visual Persuasive Factors

This repository accompanies our EMNLP 2026 Findings paper on diagnosing visual persuasive factors in vision-language models.

## Status

Code and data: TBA

## Overview

We introduce a behavioral diagnostic framework for analyzing visual persuasive factors in image--message pairs.

The framework studies perceptual, compositional, and semantic factors, including:

- Color and brightness
- Saliency and message-related regions
- Key-object, human, and text presence
- Human--model agreement and error patterns

Additional code, data, and documentation will be released after publication.
